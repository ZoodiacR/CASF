# .claude\ — CASF Framework

Structure:
- agents\     -> Specialist agent definitions
- commands\   -> Slash commands (/start-project, /new-sprint, ...)
- workflows\  -> Multi-step orchestrated processes
- templates\  -> Reusable document templates
- memory\     -> Long-term project memory
- logs\       -> Session logs

All files are STUBS until the CASF Filler Prompt is executed.
